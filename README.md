# Touchline Manager — Starter Project

A desktop football management simulation starter built with Electron, React and Phaser 3.

## Requirements
- Node.js 20.19+ or a current supported LTS release
- npm
- Windows, macOS or Linux

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

The build command creates packaged application bundles in the `out/` directory. A distributable installer/package still requires a packaging configuration such as electron-builder or Electron Forge.

## Current starter features
- Electron desktop window
- React management dashboard
- Fictional starter club and player data
- Squad overview
- Basic Phaser 2D pitch preview
- Navigation shell for planned modules

## Not implemented yet
- Actual match simulation
- Transfers and contract transactions
- League schedule and standings simulation
- Career save/load
- Scouting, youth and finance logic
- Installer packaging

See `AGENTS.md` for the rules Codex should follow when extending the project.
